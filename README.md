# Использование Antigravity из России — без VPN, без смены региона

Утилита под Windows, дающая возможность работать с Antigravity на аккаунте Google из любого региона, включая Россию.

Настройка выполняется однократно на каждом ПК. Потом можно заходить под любым Google-аккаунтом независимо от страны.

# Загрузка

Перейдите в раздел [Releases](https://github.com/KebiLab/AntigravityUnlock/releases) и скачайте актуальную сборку.

# Порядок действий
1) Установите Antigravity / Antigravity IDE / Antigravity CLI с официальной страницы [antigravity.google/download](https://antigravity.google/download)
2) Запустите анлокер и выберите нужный пункт
3) Откройте Antigravity и авторизуйтесь в Google-аккаунте

# Совместимость

Анлокер поддерживает весь актуальный стек Google-инструментов для разработки:
- Antigravity 2.0
- Antigravity IDE
- Antigravity CLI
- Gemini CLI

# Какие изменения вносит анлокер?

Программа затрагивает ровно три компонента, каждый из которых откатывается обратно через пункт меню `Полный откат`. Дополнительно задаётся переменная окружения `HTTPS_PROXY` (подробности ниже).

1. **Исполняемые файлы Language Server / CLI** (`language_server.exe`, `agy.exe`) — в protobuf-дескрипторе одно поле переименовывается (`ineligible` → `inexigible`). Байтовая длина совпадает, структура и размер файла остаются прежними.
2. **DNS-правила NRPT** — затрагиваются только два домена, с которыми непосредственно общается Antigravity. Они направляются на альтернативный резолвер:
   `daily-cloudcode-pa.googleapis.com` и `generativelanguage.googleapis.com`.
   Весь остальной трафик (`accounts.google.com`, другие `*.googleapis.com` и т. д.) проходит через стандартный системный DNS.
3. **Предпочтение IPv4 перед IPv6** — активируется лишь при отсутствии глобального IPv6-адреса и убирается при откате.

Начиная с версии Antigravity 2.4 файлы `app.asar` не затрагиваются вообще.

### Про приватные маршруты

Для ускоренного обхода используются адреса сторонних прокси-серверов и ключ к промежуточному узлу — они **не включены** в публичный репозиторий (вынесены в файлы за пределами git). Причина — не секретность подхода (обычный `CONNECT`, весь код открыт), а практическая: публично указанные бесплатные серверы долго не живут.

Сборка из открытых исходников компилируется и работает полноценно, но **только через DNS-метод** — а его достаточно для полной разблокировки Antigravity. Собственный прокси можно указать при любой сборке: программа спросит об этом в первом пункте меню.
