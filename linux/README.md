# Antigravity Unlocker — Linux (бета-версия порта)

Снятие региональных ограничений Antigravity 2.0 / IDE / CLI под Linux. Выполняет два действия:

1. **Модификация клиентских бинарников и JS** — отключает проверку eligibility.
2. **Локальный прокси-маршрут (обход серверной ошибки 400 «User location is not supported»)** —
   запускает прокси на локальной машине и перенаправляет запросы к серверам Google через
   узел в разрешённом регионе, что устраняет блокировку по геолокации.
   Отдельный VPN или внешний прокси **не требуется** — выход встроен.

Всё выполняется **от имени обычного пользователя, без root** (sudo не запрашивается).

## Быстрый старт

1. Извлеките архив. **Если архив лежит на общей папке виртуальной машины** (`/mnt/hgfs/…` для VMware,
   `/media/sf_…` для VirtualBox) — **перенесите папку в домашнюю директорию**: общие
   папки монтируются с флагом `noexec`, и запуск оттуда невозможен.
2. Правой кнопкой по **`launch.sh`** → **«Запустить как программу» / «Run as a
   Program»**. Откроется терминал с меню — выбирайте **1**.

   Пункт «Run as a Program» отсутствует? Выполните один раз `bash install.sh` — утилита
   появится в меню приложений, после чего запускается обычным двойным кликом.

3. После применения пункта 1 **полностью закройте Antigravity и запустите заново** — language
   server подхватит настройки прокси, и ошибка 400 исчезнет.

## Как откатить изменения

Пункт **6** в меню (полный откат) или **5** (только отключение прокси) — удалят
локальный прокси, переменную `HTTPS_PROXY` и отменят патч. Для ручного отката: удалите
`~/.config/environment.d/ag-unlocker.conf` и выполните `systemctl --user disable --now
ag-unlocker-proxy`.

## Если установка не обнаружена автоматически

Пункт **3** — ручное указание пути. Типичные расположения: `/opt/antigravity`,
`~/.local/share/antigravity`, `~/.local/bin` (CLI). Snap-версия не поддерживается
(файловая система доступна только на чтение) — используйте обычную установку.

## Состав пакета

| Файл | Описание |
|---|---|
| `ag_unlocker` | основной инструмент — патчер + прокси (ELF x86-64) |
| `launch.sh` | скрипт-обёртка: открывает терминал, запускает от текущего пользователя |
| `Antigravity-Unlocker.desktop` | ярлык для меню приложений |
| `install.sh` | устанавливает ярлык в системное меню |
